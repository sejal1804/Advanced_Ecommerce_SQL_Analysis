# Advanced E-commerce SQL Analysis

## Problem Statement

An e-commerce business stores information about customers,
products, orders, order items, and payments across multiple
relational tables. The objective is to analyze this data using
MySQL and generate meaningful business insights.

## Objectives

- Analyze customer purchasing behavior
- Analyze product performance
- Analyze sales and revenue
- Analyze order trends
- Analyze payment activity
- Perform advanced SQL analysis

## Tools & Technologies

- MySQL

## Database Structure

Customers
Products
Orders
Order Items
Payments

## SQL Concepts Used

- Primary & Foreign Keys
- Data Cleaning
- JOINs
- GROUP BY
- Aggregations
- CTEs
- Subqueries
- Window Functions
- RANK()
- ROW_NUMBER()
- LAG()

## Key Analysis

- Top customers by sales
- Top products by revenue
- Revenue by category
- Running monthly sales
- Month-over-month sales change
- Customer sales ranking
